# DashCat

一个轻量的 Windows 11 系统托盘工具，把系统监控、防休眠和鼠标滚轮反转合在一只会奔跑的小猫里。

---

任务栏右下角总跑着好几个小工具：一个看系统负载，一个防休眠，还要处理外接鼠标滚轮方向。多个图标、多个后台进程，总觉得浪费。索性自己动手，重新设计，只保留最常用的功能：系统监控、防休眠和鼠标滚轮反转。监控逻辑高效准确，防休眠和滚轮反转直接内置。恰到好处，不花哨。

DashCat 就是这么来的。一只小猫蹲在系统托盘，跑得快说明电脑负载高；右键点一下，防休眠、鼠标滚轮方向、监控模式一目了然。一个图标，多个常用工具的活全干了。零依赖，极低资源占用，数据全部存在本地。

---

## 功能

- **系统监控**
  - 三种监控模式：综合、CPU、内存
  - 猫咪动画速度实时反映系统压力——跑得越快，负载越高
  - 综合模式下自动取 CPU 和内存中压力更高者驱动动画
  - 显示方式可选：动画与百分比、仅动画、仅百分比、双数值
  - 鼠标悬停显示详细数值

- **防止休眠**
  - 关闭：正常，允许系统休眠
  - 阻止系统休眠：防止系统空闲休眠（屏幕仍可关闭）
  - 阻止屏幕关闭：防止显示器进入睡眠
  - 右键菜单直接选择，状态实时生效

- **其他特性**
  - 可反转外接鼠标滚轮方向，触控板保持正常
  - 支持开机启动
  - 节能设计：动画刷新率 200ms，系统资源占用极低
  - 零外部依赖，纯 Win32 API

## 系统要求

- Windows 11（64 位）

## 安装

**方式一：直接下载**

1. 进入本仓库的 [Releases](../../releases) 页面，下载最新的 `dashcat-win.exe`
2. 双击运行即可

**方式二：自行编译**

需要 Rust 和 mingw-w64 交叉编译环境：

```bash
# 安装目标
rustup target add x86_64-pc-windows-gnu

# 构建
cargo build --release --target x86_64-pc-windows-gnu
```

## 使用

- **右键点击**猫咪图标：打开设置菜单
  - 切换监控模式（综合 / CPU / 内存）
  - 切换显示方式（动画+百分比 / 仅动画 / 仅百分比 / 双数值）
  - 切换防休眠模式
  - 反转鼠标滚轮
  - 设置开机启动
  - 退出程序

## 常见问题

**猫咪动画速度代表什么？**

动画速度反映系统负载。跑得越快，说明 CPU 或内存使用率越高。综合模式下自动取两者中更高者驱动动画。

**如何开启开机自启？**

右键点击猫咪图标 → 勾选「开机启动」。程序会在注册表中添加启动项。

**反转鼠标滚轮有什么用？**

如果你习惯 macOS 的「自然滚动」方向，或外接鼠标和触控板滚动方向不一致，可以开启此功能反转鼠标滚轮方向，触控板不受影响。

**程序数据存在哪里？**

设置保存在 `%APPDATA%\DashCat\settings.json`。如需重置，删除此文件即可。

**资源占用如何？**

程序采用纯 Win32 API 实现，无 UI 框架依赖。内存占用约 2-5MB，CPU 占用可忽略不计。
