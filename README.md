# DashCat

一只会跑的小猫，蹲在 Windows 11 系统托盘里帮你监控系统。

---

## 功能

**系统监控**
- 猫咪动画速度反映负载高低——跑得越快，负载越高
- 三种监控模式：综合（CPU+内存）、仅 CPU、仅内存
- 四种显示方式：动画+百分比、仅动画、仅百分比、双数值
- 鼠标悬停显示详细数值

**防止休眠**
- 关闭：允许正常休眠
- 阻止系统休眠：防止空闲休眠（屏幕可关闭）
- 阻止屏幕关闭：显示器保持常亮

**其他**
- 支持开机启动
- 纯 Win32 API，零依赖
- 内存占用约 2-5MB

---

## 安装

从 [Releases](../../releases) 下载 `DashCat.exe`，双击运行。

## 使用

右键点击托盘图标：
- 切换监控模式
- 切换显示方式
- 设置防休眠
- 开机启动
- 退出

## 系统要求

- Windows 11 64 位

## 数据存储

设置保存在 `%APPDATA%\DashCat\settings.json`，删除即可重置。
