# 功能设计

## 模块概览

| 模块 | 说明 | 对应 macOS 模块 |
|------|------|-----------------|
| 系统托盘 | 托盘图标、右键菜单、动画渲染 | AppDelegate (statusItem) |
| 系统监控 | CPU/内存使用率采集 | SystemMonitor |
| 剪贴板管理 | 历史存储、搜索、复制 | ClipboardManager + ClipboardPanel |
| 防休眠 | 电源管理控制 | CaffeineMode |
| 鼠标滚轮反转 | 全局鼠标钩子 | ScrollManager |
| 数据持久化 | SQLite 存储、配置管理 | ClipboardManager (SQLite) |

---

## 模块一：系统托盘

### 功能列表

- [ ] 托盘图标显示（猫咪动画）
- [ ] 左键点击打开剪贴板面板
- [ ] 右键点击打开设置菜单
- [ ] 动画帧切换（根据 CPU/内存负载）
- [ ] 图标颜色变化（休眠模式指示）
- [ ] 数值显示（CPU/内存百分比）

### 业务逻辑

```
启动 → 加载配置 → 初始化托盘图标 → 启动监控定时器
    ↓
监控定时器 (5s间隔) → 采集 CPU/内存 → 计算动画帧率 → 更新图标
    ↓
左键点击 → 显示剪贴板面板
右键点击 → 显示设置菜单
```

### 边界情况

- 托盘区域被隐藏：正常工作，用户需手动显示托盘
- 多显示器：面板跟随托盘图标所在显示器
- 高 DPI 屏幕：图标自动缩放

---

## 模块二：系统监控

### 功能列表

- [ ] CPU 使用率采集
- [ ] 内存使用率采集
- [ ] 综合模式（取两者较高值）
- [ ] 单独 CPU 模式
- [ ] 单独内存模式

### 业务逻辑

```
PDH API 初始化 → 创建计数器查询
    ↓
定时采样 (5s) → PdhCollectQueryData
    ↓
计算使用率 = (当前 - 上次) / 总量
```

### 边界情况

- 计数器不存在：使用备用方案 (GetSystemTimes)
- 采样间隔过短：限制最小 1 秒

## 模块三：剪贴板管理

### 功能列表

- [ ] 文本历史记录
- [ ] 图片历史记录（可选开关）
- [ ] 搜索过滤
- [ ] Pin 固定
- [ ] 删除单条/清空历史
- [ ] 历史保留天数设置
- [ ] 自动清理过期记录

### 业务逻辑

```
剪贴板变化检测 (轮询 1s)
    ↓
判断类型 → 文本/图片
    ↓
去重检查 → 已存在则跳过
    ↓
存储 → SQLite + 图片文件
    ↓
通知 UI 刷新
```

### 边界情况

- 大文件复制：跳过 > 10MB 的数据
- 敏感内容：不自动跳过，由用户决定是否删除
- 图片存储上限：500MB 自动清理最旧未固定图片

---

## 模块四：防休眠

### 功能列表

- [ ] 关闭（正常休眠）
- [ ] 阻止系统休眠（屏幕可关闭）
- [ ] 阻止屏幕关闭

### 业务逻辑

```
用户选择模式 → 调用 SetThreadExecutionState
    ↓
关闭 → 不调用任何阻止
阻止系统休眠 → ES_SYSTEM_REQUIRED
阻止屏幕关闭 → ES_DISPLAY_REQUIRED | ES_SYSTEM_REQUIRED
```

### 边界情况

- 程序崩溃：Windows 自动释放休眠阻止
- 笔记本合盖：受电源计划影响，可能仍休眠

---

## 模块五：鼠标滚轮反转

### 功能列表

- [ ] 全局鼠标滚轮事件拦截
- [ ] 反转滚轮方向（仅鼠标，触控板不变）
- [ ] 开关控制

### 业务逻辑

```
开启 → SetWindowsHookEx(WH_MOUSE_LL)
    ↓
拦截滚轮事件 → 判断设备类型
    ↓
鼠标 → 反转 delta 值
触控板 → 保持原值
```

### 边界情况

- 权限不足：提示用户以管理员运行
- 游戏/全屏应用：钩子可能被绕过
