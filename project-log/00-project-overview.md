# 项目概述

## 项目名称

DashCat-Win — Windows 版系统托盘猫咪工具

## 项目背景

DashCat 是一个 macOS 菜单栏工具，将剪贴板历史、系统监控、防休眠和鼠标滚轮反转整合在一个会奔跑的小猫图标中。本项目是 DashCat 的 Windows 移植版本，目标让用户在切换系统时获得一致的使用体验。

**原版仓库**：`~/projects/dashcat` (macOS Swift + AppKit)

**目标用户**：需要在 Windows 和 macOS 之间切换的用户，希望工具体验一致。

## 用户 / 使用场景

- 跨平台工作者：在 Windows 办公、macOS 开发，需要统一的工具体验
- 轻量工具偏好者：不想安装多个独立工具（剪贴板管理器、系统监控、防休眠）
- 资源敏感用户：追求最小内存占用、最快启动速度

## 核心功能

1. **系统监控** — CPU/内存实时监控，猫咪动画速度反映负载
2. **剪贴板管理** — 历史记录、搜索、Pin 固定、图片支持
3. **防止休眠** — 三档控制：关闭/阻止系统休眠/阻止屏幕关闭
4. **鼠标滚轮反转** — 仅对鼠标生效，触控板保持自然滚动
5. **多语言支持** — 11 种语言界面
6. **开机启动** — 注册表自启动

## 核心概念

- **系统托盘图标**：Windows Taskbar Notification Area，右下角托盘区域
- **猫咪动画**：5 帧 PNG 逐帧播放，速度映射系统负载
- **休眠模式**：通过 Windows Power Management API 控制

## 技术栈

| 层级 | 技术 | 说明 |
|------|------|------|
| 语言 | Rust 1.75+ | 内存安全、零依赖运行时 |
| GUI | Win32 API (windows-rs) | 纯系统调用，无框架 |
| 数据库 | SQLite (rusqlite) | 剪贴板历史存储 |
| 图像解码 | png crate | PNG 动画帧解码 |
| 系统监控 | PDH (Performance Data Helper) | Windows 性能计数器 |
| 剪贴板 | Win32 Clipboard API | 剪贴板监控 |
| 防休眠 | SetThreadExecutionState | Windows 电源管理 |
| 构建目标 | x86_64-pc-windows-gnu | 交叉编译 |

## 项目边界

- **不包含**：网络功能、云同步、账号系统
- **不包含**：GUI 设置窗口（使用右键菜单代替）
- **不包含**：32 位 Windows 支持

## 项目约束

- **兼容性**：Windows 11 x86_64（Windows 10 21H2+ 可能兼容但非目标）
- **资源限制**：内存占用 < 5MB，二进制 < 2MB
- **启动速度**：< 100ms 冷启动
- **体验一致**：与 macOS 版功能对等，UI 风格一致
