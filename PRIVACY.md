# DashCat Privacy Policy

**Last Updated:** May 2026

## Data Collection

DashCat does **not** collect, store, or transmit any personal data to external servers.

## Local Data Storage

DashCat stores the following data locally on your device:

- **Settings**: Monitor mode, display preferences, and sleep prevention settings are stored in the application data folder.
- **Configuration**: Auto-start preference is stored in the Windows Registry (HKCU\Software\Microsoft\Windows\CurrentVersion\Run).

## Network Access

DashCat operates entirely offline. No internet connection is required or used.

## System Access

DashCat accesses the following system resources:

- **CPU/Memory**: Read-only access to display system usage statistics.
- **Power Management**: Ability to prevent system sleep when enabled by user.
- **Clipboard**: (Optional feature) Clipboard history is stored locally if enabled.

## Third-Party Services

DashCat does not integrate any third-party analytics, advertising, or tracking services.
